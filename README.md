# 🧞 SpeakGenie — A Magical AI Companion for Kids!

**SpeakGenie** is a voice-interactive chatbot built specially for children aged 6 to 16. With engaging visuals, cheerful voice replies, and roleplay-based personalities like a magical genie, friendly teacher, or warm storyteller — SpeakGenie makes learning feel like play!

---

## 🎯 What is SpeakGenie?

SpeakGenie is a child-friendly AI web app that allows kids to:
- ✨ Ask questions by speaking or typing
- 📚 Choose a learning mode: Genie, Teacher, or Storyteller
- 🎤 Get instant voice + text replies using real AI voices

---

## 🧠 Key Features

✅ Voice and Text input  
✅ LLM-powered intelligent replies (LLaMA 3 via Groq)  
✅ Real-time speech synthesis (via ElevenLabs)  
✅ Mode-based personalities with separate prompts  
✅ Colorful, animated UI designed for kids  

---

## 💻 Technologies Used

| Layer        | Tech Stack                          |
|--------------|-------------------------------------|
| Frontend     | HTML, CSS, JavaScript (modular)     |
| Backend      | Flask (Python)                      |
| AI Model     | Groq API (LLaMA 3 - 70B)            |
| TTS Engine   | ElevenLabs API                      |
| STT Engine   | whisper.cpp                         |
| Deployment   | Runs locally via `python app.py`    |
